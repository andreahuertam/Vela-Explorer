## 📌 Sobre el proyecto

dbv-specs-ops es una plantilla y framework de desarrollo que ayuda a que los asistentes de IA trabajen con la disciplina de un ingeniero de software senior, siguiendo un ciclo estructurado de desarrollo dirigido por especificaciones (Spec-Driven Development).

**Tecnologías principales:** Markdown, Shell, Python, JavaScript

---

## 🧰 Requisitos

- Node.js 20+ (para interactuar si se tienen herramientas asociadas) o cualquier entorno básico compatible.
- Git (para el control de versiones)

## ▶️ Cómo ejecutar

Utiliza los scripts de inicio incluidos en la raíz del proyecto (a crear durante la fase de construcción):

**Windows:**
```cmd
start.cmd
```

**macOS / Linux:**
```bash
./start.sh
```

---

## ⏹ Cómo parar

**Windows:**
```cmd
stop.cmd
```

**macOS / Linux:**
```bash
./stop.sh
```
